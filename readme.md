# BiliJump

BiliJump 是一个简单的 Bilibili 平台视频内口播广告智能跳过插件。理论上，只要视频有 AI 字幕（UP 主没有手动关闭且 AI 字幕已经生成完成），插件就可以发挥作用。实际上，由于插件尚没有对长视频做优化，仅15分钟以下的视频有较好的识别率。

## 工作原理

在打开一个视频页面后，BiliJump 执行以下操作：

1. 读取 BV 号，使用 B 站官方 API 获取所提供的 AI 字幕。
2. 将 AI 字幕输入到大模型中，指示其搜寻其中的口播广告部分。
3. 在网页中监听视频进度，自动跳过广告时间段。

**Update: 由于 B 站对字幕信息 API 的调整，如今获取到的字幕内容可能出现与视频不匹配的情况，这可能是一种反爬取的随机化手段。因而 BiliJump 可能无法正常对视频解析，这个问题暂时没有被修复。**

## 使用方法

1. **安装插件**
  你可以在 release 找到插件的 crx 文件，启用浏览器的开发者模式并拖入安装即可。如果你使用的是 Edge 浏览器，则其可能已经禁止加载 crx 文件，可以下载 rar 格式文件并解压，通过“加载解压缩的拓展”功能完成安装。
2. **配置 key**（可选）
  默认情况下， BiliJump 会使用已经搭建好的后端服务，无需额外配置。如果你想要使用自己的 api，可以打开插件界面输入相关的 key, url 与模型名称。请注意，默认的 url 是 GLM 模型的，修改为其他可能触发安全策略而导致请求被阻止，你需要手动在脚本配置中添加对应的 url。
3. **测试效果**
  打开一个视频，你应当可以在简介栏下方看到以下三种提示之一：
     - 绿色文字提示发现广告，将会自动跳过。你可以手动取消。
     - 灰色文字提示没有发现广告，你可以重试。
     - 红色文字提示无法正确找到字幕信息，可能是视频没有对应的 AI 字幕，你可以重试。

## 已知问题

- 插件效率有待优化
- 直接在视频页中跳转，有概率无法触发插件
- 长视频的识别并不稳定
- 没有对特殊视频页面做测试和适配
